- **Day 3: Legs & Calves** (Lower Body Domination)

- **Day 5: Full Body Functional & HIIT Conditioning**

*Every single exercise includes:*

## 🚀 How to Run the Website

### Option 1: Double-Click (Zero Setup Needed)
Simply open the folder and double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox. Everything works offline!

### Option 2: Run a Local Dev Server
In your terminal, navigate to this folder and run:
```bash
npx serve .
# Or using Python:
python -m http.server 8000
```
Then open `http://localhost:3000` or `http://localhost:8000` in your browser.
